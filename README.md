🎮 FaceQuiz

O FaceQuiz é um jogo interativo de perguntas e respostas desenvolvido com HTML, CSS e JavaScript. O objetivo é identificar pessoas por meio de imagens e selecionar a alternativa correta antes que o tempo acabe.

✨ Funcionalidades

🎯 Perguntas e alternativas aleatórias a cada partida.

⏱️ Cronômetro para responder às perguntas.

🏆 Sistema de pontuação baseado nos acertos.

🎁 Fase Surpresa com vídeo, áudio e bônus de 500 pontos.

🔊 Efeitos sonoros para acertos e erros.

🎨 Interface moderna, interativa e responsiva.

📊 Tela de resultados com pontuação, acertos, erros e percentual de aproveitamento.

🥇 Ranking de jogadores.



🛠️ Tecnologias utilizadas

HTML5: estrutura das telas e dos elementos do jogo.

CSS3: estilização, layout responsivo, animações e efeitos visuais.

JavaScript: lógica das perguntas, alternativas, cronômetro, pontuação, reprodução de vídeo e interações.



🚀 Como executar

Clone ou baixe este repositório.

Abra a pasta do projeto.

Abra o arquivo index.html no navegador.

Clique em iniciar e divirta-se!



📁 Estrutura do projeto

index.html — estrutura do jogo.

style.css — estilos e animações.

script.js — lógica e funcionalidades.

imagens/ — imagens utilizadas nas perguntas.

videos/ — vídeos utilizados na Fase Surpresa.



🎯 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar os fundamentos do desenvolvimento web, incluindo manipulação do DOM, eventos, funções, arrays, temporizadores, organização de interfaces interativas com um proposito especial



💖 O propósito especial do FaceQuiz

Mais do que um jogo de perguntas e respostas, o FaceQuiz foi desenvolvido com um objetivo muito especial: revelar uma gestação em andamento aos familiares de uma forma criativa, interativa e emocionante.

Ao longo do jogo, os participantes respondem a perguntas, acumulam pontos e se divertem com os desafios. A experiência foi pensada para conduzir a família a uma surpresa inesquecível, transformando a descoberta da chegada de um novo membro da família em um momento único, cheio de expectativa, amor e emoção.

O projeto une tecnologia, criatividade e sentimentos, mostrando como o desenvolvimento de software pode ser utilizado para criar experiências personalizadas e eternizar momentos importantes da vida.

🎁 A surpresa final: uma nova vida está a caminho! 👶💕
